Create a modern landing page for an AI presentation platform called “Jormun Deck”. Jormun Deck is an AI presentation architect for creating professional decks. It is not just a simple AI slide generator. Its main innovation is an interactive Slide Logic system. The platform works like this: 1. The user gives information about their project, startup, product, research, idea, or topic. 2. Gemini analyzes the goal, audience, presentation type, tone, and missing information. 3. The system asks smart clarification questions only when needed. 4. Gemini creates a full slide-by-slide logic plan before generating the design. 5. The user sees a Slide Logic Board where every slide is represented as a card. 6. The user can click each slide card to see what the slide will contain: purpose, main message, suggested content, visual idea, layout direction, tone, and role in the story. 7. The user can change the logic by giving natural-language feedback, for example: “This slide should explain our AI personalization system,” or “Remove the market slide,” or “Make this deck for schools, not investors.” 8. If the feedback changes the presentation strategy, Jormun Deck rebuilds the whole architecture, not just one slide. 9. After the logic is approved, the platform offers visual style variants such as Serious Investor, Artistic Founder, Luxury Minimal, Brutalist Blossom, Tech Noir, Corporate Clean, Academic Clear, and Startup Bold. 10. After the user chooses a style, Jormun Deck generates the final presentation using AI writing, layout generation, and ChatGPT image generation for custom visuals.
